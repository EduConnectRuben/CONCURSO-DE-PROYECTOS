## 🎯 Objetivo
Demonstrar cómo los conocimientos adquiridos en la carrera de Sistemas Informáticos se transforman en oportunidades concretas de emprendimiento y creación de negocios propios.

## 📚 Estructura Formativa
La carrera se organiza en 3 niveles, cada uno de 1 semestre:
- 🟢 **Técnico Básico**: Hardware, Sistemas Operativos, Diseño y Publicidad con IA
- 🟡 **Técnico Auxiliar**: Máquinas Virtuales, Ofimática Avanzada, Redes
- 🔴 **Técnico Segundo (I y II)**: Programación, Bases de Datos, Desarrollo y Gestión de Proyectos

## 🚀 Tecnologías Usadas
- HTML5 — Estructura del proyecto
- CSS3 — Diseño y adaptabilidad a cualquier pantalla
- JavaScript — Interacción y navegación dinámica

## 📂 Cómo usar el proyecto
1. Descarga todos los archivos en una misma carpeta
2. Abre el archivo `index.html` en cualquier navegador
3. Agrega tus imágenes, videos y archivos multimedia reemplazando los nombres en el código
